# Contract Change Request: m33-1

**Module:** M33 — Open-data Coverage
**Requested by:** implementer agent syn-m33
**Blocking:** Yes — M33 providers cannot type `FeedProvider.id` as a contract-safe `FeedProviderId` without this change.
**Workaround applied:** local type redefinition (same pattern as `apps/worker/src/feeds/ofac-provider.ts`).

## Request

Add 6 new entries to `FEED_PROVIDER_IDS` and `FEED_PROVIDER_REGISTRY` in
`specs/contracts/06-feed-providers.contract.ts`.

All 6 are free-tier Wave-2 providers (M33).

| ID | Name | cost_model | cost_per_request_inr | requires_api_key | wave |
|---|---|---|---|---|---|
| `weather-noaa` | NOAA National Weather Service | free | 0 | false | 2 |
| `tariffs-wto` | WTO Tariff Download Facility | free | 0 | false | 2 |
| `regulatory-fda` | Regulatory Feed (Federal Register / EUR-Lex / India Gazette) | free | 0 | false | 2 |
| `sanctions-ofac` | OFAC Update Events (additive to M17 `ofac-sanctions` screening) | free | 0 | false | 2 |
| `maritime-imo` | IMO Maritime Safety Information | free | 0 | false | 2 |
| `currency-ecb` | ECB Euro Reference Exchange Rates | free | 0 | false | 2 |

## Notes

- `sanctions-ofac` is intentionally distinct from `ofac-sanctions` (M17).
  `ofac-sanctions` screens watchlist entities against the SDN list.
  `sanctions-ofac` ingests OFAC list-update events into the events collection.
- No rate limits exceed existing registered providers.
- No paid-tier changes — all free, no `withCostGate` enforcement needed.
