# Contract Change Request: M38-1

**Module:** M38 PLG Onboarding Pack  
**Request ID:** m38-1  
**Status:** Pending Approval  
**Date:** 2026-05-10

## Summary

Add a new LLM prompt to the prompt registry for extracting company metadata from website content and annual report text. This prompt powers the "Onboard from URL" feature (#81) which fetches webpage content and structured-extracts:
- Company name
- Sector/industry
- Country/region
- Top suppliers (entities)
- Top customers (entities)
- Key facilities/locations
- Top counterparties

## Changes Required

### Addition to `specs/contracts/05-llm-prompts.contract.ts`

**New prompt entry: `COMPANY_METADATA_EXTRACT`**

```typescript
// =========================================================================
// COMPANY_METADATA_EXTRACT
// Extracts company metadata from webpage content or annual report text.
// Used by: M38 PLG Onboarding (#81 "Onboard from URL")
// =========================================================================

const CompanyMetadataExtractInputsSchema = z.object({
  input_text: z.string().min(100).max(50000),  // fetched page content or PDF text
  input_source: z.enum(['webpage', 'annual_report']),
});

const CompanyMetadataExtractOutputSchema = z.object({
  company_name: z.string().nullable(),
  sector: z.string().nullable(),        // e.g., "Pharmaceuticals", "Logistics"
  country: z.string().nullable(),       // ISO 2-letter code
  region: z.string().nullable(),        // e.g., "South Asia", "Southeast Asia"
  suppliers: z.array(z.object({
    name: z.string(),
    confidence: z.number().min(0).max(1),
    excerpt: z.string(),                // source quote
  })).max(10),
  customers: z.array(z.object({
    name: z.string(),
    confidence: z.number().min(0).max(1),
    excerpt: z.string(),
  })).max(10),
  facilities: z.array(z.object({
    name: z.string(),
    location: z.string().nullable(),
    confidence: z.number().min(0).max(1),
    excerpt: z.string(),
  })).max(5),
  counterparties: z.array(z.object({
    name: z.string(),
    type: z.enum(['supplier', 'customer', 'partner', 'competitor']).nullable(),
    confidence: z.number().min(0).max(1),
    excerpt: z.string(),
  })).max(10),
});

export const COMPANY_METADATA_EXTRACT = {
  id: 'COMPANY_METADATA_EXTRACT',
  version: '1.0.0',
  model: 'claude-haiku-4-5',
  system: 'You are an intelligence analyst extracting company metadata from business documents. Extract only entities that are explicitly mentioned or strongly implied. Rate confidence 0–1. Do not guess or hallucinate entities.',
  template: `Source: {{input_source}}

Content:
{{input_text}}

Extract company metadata: name, sector, country/region, major suppliers (with excerpt), major customers (with excerpt), key facilities, and notable counterparties. For each entity, include a source excerpt and confidence score 0–1. Omit entities with <0.6 confidence. Return JSON.`,
  expected_inputs: CompanyMetadataExtractInputsSchema,
  expected_output_format: CompanyMetadataExtractOutputSchema,
} satisfies PromptRegistryEntry<typeof CompanyMetadataExtractInputsSchema, typeof CompanyMetadataExtractOutputSchema>;
```

### Addition to LLM_PROMPT_REGISTRY

Add `COMPANY_METADATA_EXTRACT` to the `LLM_PROMPT_REGISTRY` export.

## Rationale

- **Why this prompt:** M38 (#81) onboards new customers from URL or annual report in <5 minutes. The extraction prompt must be fast (Haiku), reliable, and high-recall for supplier/customer mentions.
- **Why Haiku:** Fast + cheap; extraction task is straightforward entity recognition, no reasoning needed.
- **Schema design:** Confidence scores per entity allow the review UI to highlight high-confidence extractions and flag low-confidence ones for manual review. Excerpts enable users to verify the source.

## Implementation Notes

- **Fallback (no API key):** When `ANTHROPIC_API_KEY` is not set, use a mock extraction in packages/shared/mocks/anthropic.ts that returns stub data.
- **Timeout:** Server-side fetch in the API route uses 10s timeout, max 2MB. Excess content is truncated before LLM call.
- **Max context:** Truncate input_text to 50KB to stay within reasonable token budgets.
- **Caching:** Each extraction run is tagged with `prompt_id: 'COMPANY_METADATA_EXTRACT'` and `version: '1.0.0'` for audit.
